# 安全与兼容范围

- 服务没有客户端密码认证，使用来源 IP/CIDR 和目标域名限制。仅绑定可信 LAN 地址，只放行实际需要的单设备。不做公网映射，不使用 `0.0.0.0/0` 或 `::/0` 白名单。
- 若设备经过 NAT 或网关转发，旁路由可能看到的是共同的来源 IP。不要把网关地址加入白名单来冒充单设备授权。先确认流量来源，再决定是否部署。
- 普通 HTTP 只允许目标 80 端口，HTTPS CONNECT 只允许 443。直接出站时程序拒绝非公网 DNS 结果并对已核验的地址拨号；使用上游后，由上游解析和连接目标，因此必须信任该上游。HTTPS 由客户端端到端校验证书，本程序不提供 TLS 解密。
- 代理日志面向目标、结果和耗时，不用于记录完整请求。分享诊断前仍要脱敏：删除实际地址、设备标识、账号、令牌、签名链接、订阅信息及未经裁剪的截图。
- 首发文档只涵盖核心代理。LuCI 附加界面、专用抓包工具和 PS5 的独立代理入口，不是此安装流程的一部分。需要扩展部署时，应先检查可配置性、权限和回退，再单独验收。

提交问题时，请提供固件与架构、核心版本、是否使用上游、是否出现错误状态，以及「Wi-Fi → 代理 → PSN → 进入串流」卡在哪一步。用合成地址和已脱敏日志，避免附设备备份或原始抓包。
